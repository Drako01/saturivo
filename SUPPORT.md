# Saturivo Support / Soporte

Saturivo is an open-source **pre-release** VS Code extension; the repository is public, but no published Marketplace or Open VSX version is guaranteed yet.

## Get help

- **Bug or feature:** [open an issue](https://github.com/Drako01/saturivo/issues/new/choose) after checking existing reports.
- **General support:** [ArmoTuSitio support](https://armotusitio.com.ar/soporte/) — mention **Saturivo**.
- **Security disclosure:** follow [SECURITY.md](SECURITY.md); do **not** post a public issue.
- **Collaboration standards:** [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

For a bug, share the Saturivo version/commit, VS Code version, OS and extension host (local, WSL, SSH, container), Node/Go/k6 versions where applicable, steps to reproduce, expected vs. observed behavior and a **sanitized** minimal fixture. State whether the target was local and whether you own or are authorized to test it.

Do **not** upload internal URLs, access tokens, customer data, raw private profiles, unredacted logs, or credentials. Never point contributors to a public production endpoint for a load test.

**En español:** Para soporte, abrí un issue con información reproducible y anonimizada o contactá a [ArmoTuSitio](https://armotusitio.com.ar/soporte/). Las vulnerabilidades se reportan por canales privados.
